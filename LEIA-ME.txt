OPORTUNIDADES AÉREAS — VISUAL TURISMO (MVP 1)

Arquivos (todos ficam na raiz do repositório, sem pastas):
  index.html             o app
  dados.xlsx             a planilha com os dados (é o único arquivo que você troca no dia a dia)
  sw.js                  guarda o app no celular para abrir sem internet
  manifest.webmanifest   nome, cor e ícones do app instalado
  xlsx.mini.min.js       leitor de planilha (SheetJS)
  icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png

ATUALIZAR OS DADOS
  1. Renomeie a planilha nova para exatamente: dados.xlsx
  2. No GitHub, abra o repositório > Add file > Upload files > envie o dados.xlsx > Commit changes.
  3. Em 1 a 2 minutos o site atualiza. Os usuários recebem a versão nova ao abrir o app.
  Regras: mantenha o nome da aba "Estoque Geral" e os nomes das colunas.
          A aba "Exclusivos Visual" é opcional. As demais abas são ignoradas.

AJUSTES (no início do script do index.html, bloco CONFIG)
  ocultarVoosPassados: true    esconde saídas anteriores a hoje
  regraSemTaxa: null           ex.: { tipo: "percentual", valor: 10 } ou { tipo: "fixo", valor: 100 }
  Ao alterar index.html, aumente a VERSAO no início do sw.js (v1 -> v2).
