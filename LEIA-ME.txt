OPORTUNIDADES AÉREAS — VISUAL TURISMO (v5)

PUBLICAR / ATUALIZAR O APP
  No GitHub: Add file > Upload files > envie todos os arquivos desta pasta > Commit changes.
  Arquivos com o mesmo nome são substituídos.

ATUALIZAR OS DADOS (dia a dia)
  1. Renomeie a planilha nova para exatamente: dados.xlsx
  2. No GitHub: Add file > Upload files > envie o dados.xlsx > Commit changes.
  3. Em 1 a 2 minutos todos recebem a versão nova (ou ao puxar a tela para baixo).
  Regras: mantenha o nome da aba "Estoque Geral" e os nomes das colunas.
          A aba "Exclusivos Visual" é opcional. As demais abas são ignoradas.

AJUSTES (bloco CONFIG no início do script do index.html)
  linkReserva            endereço aberto pelos botões "Reservar"
  ocultarVoosPassados    true = esconde saídas anteriores a hoje
  regraSemTaxa           null = não mostra; ex.: { tipo: "percentual", valor: 10 }
  datasPorGrupo          quantas datas aparecem ao abrir uma rota
  Ao alterar o index.html, aumente a VERSAO no início do sw.js (v6 -> v7).

LINKS DIRETOS (para mandar a agentes)
  .../#de=São Paulo&para=Maceió
  .../#de=São Paulo&para=Maceió&mes=2026-12
  .../#temporada=reveillon   (também: carnaval, semana-santa, julho)
  .../#tipo=excl             (só exclusivas)
  .../#ultimos=1             (só saídas com até 3 lugares)
  .../#proximos=30           (saídas nos próximos 30 dias)

NOVIDADES
  Cada aparelho compara a planilha nova com a versão anterior que ele tinha.
  Saídas que não existiam aparecem como "Nova"; as que ficaram mais baratas, como "Preço baixou".
  Os selos ficam até a próxima atualização da planilha.
  O menu "Compartilhar esta busca" gera o link da busca atual.
